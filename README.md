# 11 Darts

**Free online darts leagues for everyone: one match a week, camera on, all levels welcome.**

🎯 **Play:** https://jonny-610.github.io/11-Darts/

All you need is a dartboard, darts and a camera pointed at the board. It's free. Always.

---

## How it works

1. **Sign in** with Discord or your email.
2. **Join:** accept the code of conduct, tell us your 3-dart average, and send a photo of your board with your personal code next to it. A Chalker (moderator) checks it.
3. **Placement:** play 3 matches so we can put you in the right division.
4. **League:** divisions of 6, playing everyone twice over a 10-week season, one match a week. Fixtures are revealed every Monday. The top player in each division goes up and the bottom player goes down.
5. **Challenges:** challenge anyone for a first-to-3 match. Tick **Coach me** to learn from a stronger player.
6. **Training:** 100-dart scoring, checkout 121, checkout 170, Around the Clock and doubles practice, with graphs to track your progress.

## Features

- Built-in scorer: on one phone, or online with each player on their own phone
- League tables, placement tables and a roll of honour with seasonal medals
- Both players confirm every result; disputes go to the Chalkers
- 72-hour reply rule with automatic forfeits
- Player profiles with flags, records, averages and badges
- Discord posts for fixtures, results and Chalker alerts
- Light and dark mode, following your device setting

## Safety

- Adults only (18+) at the moment.
- Every new player is checked by a Chalker before they can play.
- Players can block or report anyone. Every block starts a welfare check by the Chalkers.
- Serious breaches of the code of conduct mean a permanent ban, agreed by two Chalkers or admins.

Spotted a security problem? Please tell an admin privately in our Discord rather than posting it publicly.

## For developers

This is a single static page (`index.html`) hosted on GitHub Pages, with data stored in Supabase. The Supabase key inside `index.html` is the public "anon" key and is designed to be visible. All data is protected by row-level security and server-side checks, not by hiding the key.

**Never commit** passwords, Discord webhook addresses, the Discord Client Secret, backups or player data to this repository.
